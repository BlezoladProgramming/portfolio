# The Workshop — Distinctive UI/UX direction

**Created 17 Nov 2026.** Proposed, not yet approved by the portfolio owner.

## Why this is not a typical portfolio template

The earlier design used a conventional tall editorial hero, tiled projects, sequential services and a standard navigation header. This revision changes the visitor's interaction model and information structure:

- **Persistent vertical navigation rail** (desktop) with page indices. Mobile becomes a full-screen index drawer with Escape/focus semantics.
- **Asymmetric opening cover** with a working **interactive engineering scene**, where visitors choose *Interfaces*, *Systems* or *Improvements*. This is explicitly a conceptual illustration, never portrayed as a screenshot of a real deployed system.
- **Project Explorer** works as a selectable case-file interface, not a set of repeated clickable tiles. The public work archive is a typographic table and case studies are documentary chapters.
- **Service Desk** uses a selectable problem/solution panel in a bright, high-contrast section rather than repeating service cards.
- **Process** becomes a vertical narrative; brand story uses a monogram diagram.
- **Motion** is contextual: CSS first-load sequence; IntersectionObserver reveal of below-the-fold sections; selected-panel crossfades; orbit/dot accents; hover affordances. Reduced-motion disables effects.

## Color language

Original color family retained: dark navy (`#090f18`), muted deep teal (`#122332`), electric blue (`#55c7ff`), pale blue-white (`#eaf3f8`), near-white (`#edf5ff`), darker section dividers.

## Type and composition

System sans-serif for a light-weight install and dependable cross-platform rendering. Georgia italic accents for one expressive note. Big-but-contained headlines combined with compact, tool-like labels and meaningful fine-line engineering geometry. No stock photos or fake prototype images.

## Usability rules

No scroll hijacking, cursor traps, automatic full-screen slideshow or mandatory animation. Interactive buttons use visible pressed states; navigational links are real links. All primary content remains visible without JavaScript. Motion is disabled under reduced-motion settings. Layout adapts at 1180/960/700/410px with further manual testing planned at target widths.

## Where evidence changes the design

Replace dossier artwork with authentic screenshots only after the owner supplies approved assets and feature/role verification. Distinguish editorial art, current product screens, design concepts and production demos in captions.
